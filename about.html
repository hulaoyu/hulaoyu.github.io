关于

我是胡天宇

做交互式解释器，也做前端。喜欢把不好解释的东西拆成能动手的部分：可以点、可以拖、可以算错。

我关心的不是“把结论讲清楚”，而是“让人能自己验证一遍”。所以我的项目大多带着一组可以拖的控件、一张随时会变的图，和一串当场算出来的数字——它们不是演示，是同一个算法的另一面。

在做什么

目前主要在做 MLP 观测台：一台 2–6–1 的小机器，在两个月亮之间学一条会拐的边界，全过程都在浏览器里现算。它还在长，下一步是把它做得更像一张能动手的纸——少一点面板，多一点直接画上去的笔迹。

另一条线是前端本身：排版、深浅色、响应式、加载性能。这个站就是那条线的练习，也是我写笔记的地方。

这个站为什么长这样

第一版是一页长滚动：首屏、作品、方法、关于，全部压在一屏一屏里。内容能站住，但每加一篇笔记就要改主页面，很快就烦了。于是有了现在这个带侧栏和文章列表的版本。

版式参考了 Chirpy 主题 的骨架：左侧栏放头像和导航，右侧是文章流，长文带目录，页脚挂“最近更新”和“热门标签”。配色没有照搬，用的是观测台那套纸白、墨黑、朱红和青。

现在

在学怎么把“过程”讲得更好看，也在补一些基础：线性代数、概率、还有把 CSS 写得更省的本事。文章更新不快，但每篇都是真的做过才写。

实现与版权

站内没有分析脚本，没有第三方字体，也没有一个外部请求。正文用系统字体，代码用等宽字体；两套配色写在 CSS 变量里，跟随系统，也可以手动切换，选择记在本地。

页面由一组 HTML 片段和一个只依赖 Python 标准库的构建脚本生成。代码在 GitHub 上，RSS 可以直接订阅。
